# 成员昵称编辑 · 2026-10-23

## 使用

管理员登录 .63 后，进入「用户管理」，在目标成员卡片点击「修改昵称」。弹窗显示只读登录账号和当前昵称，输入 1 至 48 个字符后点击「保存昵称」。支持中文，自动移除首尾空白；取消或按 Escape 放弃本次输入。

保存后用户列表和昵称搜索立即更新；成员自己的页面在刷新状态时显示新昵称。访问记录的成员筛选与已有连接明细也显示当前昵称。停用成员同样可以改名，改名操作不启用其服务。

## 实现与边界

- 新增管理员接口 `POST /api/users/nickname`，仅接受 `id` 和 `display_name`；执行会话、来源与 CSRF 校验。普通成员返回 403，未登录返回 401。
- `Accounts.update_nickname()` 使用现有账号锁及原子文件写入，只提交目标成员的 `display_name`。不支持通过此接口修改登录账号、权限或其他资料；此入口只针对成员。
- 昵称保存在 `users.private.json`，沿用现有完整配置备份。昵称相同的提交不重写账号文件；保存失败时保留原有磁盘与内存数据。
- 昵称作为普通文本渲染；拒绝空白、超过长度限制、控制字符及无效 Unicode。退出登录时清空编辑器，保存结果受会话代次检查保护。
- 访问记录查询按成员 ID 关联当前昵称，历史数据库保留原有采集快照，不批量改写历史连接；已删除成员继续显示保存的历史名称。
- 成员网页会话继续有效；修改操作记录在审计中，摘要使用固定文本，不写入昵称表单正文。

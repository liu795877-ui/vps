## 通过网页选择网络出口

首次导入新版 clash-smart-routing.private.yaml，在 FlClash 使用“规则模式”，并在 STATIC-SELECT 中选择 AUTO · 网页切换。旧配置继续支持网页选择出口；要启用本次智能分流和域名列表自动同步，需要导入新版一次。

1. 点击路径中间的服务器卡片，使用本台 VPS 自身出口 198.200.49.158。
2. 点击路径右侧的静态出口卡片，后台检测目标并切换；成功后显示真实当前出口。
3. 添加服务商提供的 SOCKS5 地址、端口和认证资料后，保存并点击新出口即可切换。AUTO 身份保持不变，新增、修改、删除出口以及日常切换均无需更新客户端文件。
4. 检测失败会保留原出口。切换期间连接可能短暂重新建立，新建连接使用新的出口。
5. 若使用客户端的“出口 · 名称”固定节点，需要更新文件才能新增固定选项；网页控制使用 AUTO。智能模式下修改“强制直连”和“强制代理”列表会自动同步，无需重新导入；切换 manual/services 分流模式仍需重新导入配置。

最多支持 8 个静态出口。上游 SOCKS5 账号密码只保存在服务器；如采用来源 IP 白名单，需允许本台 VPS 的公网 IP。网页控制支持 HY2 UDP 443 与 REALITY AUTO TCP 443。HY2 已改为跟随网页选择的出口。
